# 1024 · 滑动合并

一个单文件的 2048 类滑动合并游戏。4×4 棋盘，目标是合成 1024 ——合出来之后还能继续往 2048 冲。

全部代码写在一个 HTML 文件里，没有依赖、没有构建步骤、不发起任何网络请求，双击就能玩。

## 玩法

棋盘上每次滑动都会把所有方块推向那一侧，数字相同的两块相撞时合并成一块，合并出的数值就是本步得分（2 + 2 合并成 4，得 4 分）。每滑动一次，空格中会随机生成一个新方块——90% 是 2，10% 是 4。

没有时间限制，也没有步数限制。棋盘填满且四个方向都无法再合并时，本局结束。

## 特性

- **断点续玩**——每次有效滑动后自动存档，重开页面会问你要不要接着上一局。
- **撤销**——每局 2 次，回退一整步（棋盘、分数、步数一起回退）。
- **复活**——每局 1 次，任意时刻可以在结算弹窗里移除两个最小的方块继续。
- **里程碑**——合成 1024 时触发庆祝与结算弹窗，之后可以继续挑战 2048。
- **音效与震动**——用 WebAudio 实时合成，没有任何音频文件；合并音高随方块数值上升。可一键关闭。
- **分享**——调起系统分享面板，不支持时自动降级为复制文案。
- **无障碍**——棋盘有动态 `aria-label`，每一步通过 `aria-live` 播报；尊重系统的「减弱动态效果」设置，动画会自动降级。

## 操作

| 操作 | 触摸 | 键盘 |
| --- | --- | --- |
| 移动棋盘 | 在棋盘上滑动（阈值 18px） | 方向键 / `W` `A` `S` `D` |
| 撤销一步 | 左下角撤销按钮 | `U` |
| 新游戏 | 底部「新游戏」 | `N` |
| 关闭弹窗 | 点击遮罩 | `Esc` |

## 运行

直接用浏览器打开 `code.html` 即可。

想用本地服务器跑（比如测试 `file://` 与 `http://` 的行为差异）：

```bash
python3 -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000/code.html
```

## 技术说明

单个 HTML 文件，内联 CSS 与 JS，无第三方库、无网络请求、无图片资源（图标全部是内联 SVG，配色全部是 CSS 变量）。

- 动画基于 CSS `transform` 过渡，滑动 110ms、合并 160ms，用 `will-change` 提前提升合成层。
- 方块位置通过 CSS 自定义属性 `--x` / `--y` 驱动，移动时只改这两个值，不重排 DOM。
- 音效由 Oscillator + GainNode 现场合成，首次触摸或按键时解锁 AudioContext（绕过浏览器自动播放策略）。
- 存档写在 `localStorage`：

  | 键名 | 内容 |
  | --- | --- |
  | `state_1024_v1` | 当前对局（棋盘、分数、步数、撤销与复活次数） |
  | `best_1024_score` | 历史最高分 |
  | `sound_1024_v1` | 声音与震动开关 |

## 浏览器支持

需要支持 CSS 自定义属性、`:focus-visible` 和 WebAudio 的现代浏览器（Chrome / Edge / Safari / Firefox 近几年的版本都可以）。

移动端做了 `env(safe-area-inset-*)` 与 `100svh` 适配，兼容刘海屏和地址栏收起时的视口变化；`viewport-fit=cover` 已开启。

## 已知限制

- 分数、最高分、存档全部只存在本机，换浏览器或清理站点数据即丢失，没有云端同步和排行榜。
- 撤销有次数上限（每局 2 次），不支持无限回溯。
- 只针对单人、单局设计，没有对战或每日挑战。
